## Ports on an eliminated linear mode

`eliminate()` preserves its existing closed-system behavior. It also supports
one field-aware reduction in 0.3: a `Resonator` connected through default
lowering-operator ports to one unprojected Fock-space survivor.

```python
from quchip import Capacitive, Chip, DuffingTransmon, PortNetwork, Resonator, eliminate

q = DuffingTransmon(freq=5.0, anharmonicity=-0.2, levels=3, label="q")
r = Resonator(freq=6.0, levels=4, label="r")
network = PortNetwork(label="readout_line")
network.port("readout", target=r, rate=0.03)

full = Chip(
    [q, r],
    [Capacitive(q, r, g=0.04, label="qr")],
    port_network=network,
)
reduced = eliminate(full, r).chip
```

The same SW or exact rotation used for the effective Hamiltonian carries the
full mode lowering operator into the survivor space. The resulting port therefore
owns the effective Purcell channel and output coupling; it is not duplicated
as survivor `T1`. The network graph, scalar scattering, port phase, and
exposure reference plane are retained. Internal resonator loss remains a
separate unobserved Purcell fold.

Custom port operators, collective ports that already span the eliminated
mode, nonlinear boundary targets, projected survivor bases, multiple
survivors, and ports participating in a cascade-generated Hamiltonian are
rejected in this release. Keeping the boundary mode is preferable to silently
discarding, double-counting, or guessing their transformed field physics.

## Partitioning with a field network

`chip.partition()` reads multi-device support from the resolved Hamiltonian
and Lindblad channels. A Hamiltonian generated by SLH cascade composition
connects its endpoint devices. Passive unitary scattering over independent
ports does not add dynamical support, but it can still prevent partitioning
when it couples the groups' boundary planes. Deterministic control crosstalk
remains in one component so the current component solver can preserve its
signal transform.

Separable field lines travel with their device group, including their
components, connections, exposures, tracked parameters, filter callables, and
boundary scattering. If a field subgraph spans groups, a component is not
reachable from any one group's ports, or boundary scattering couples groups,
`chip.partition()` keeps one joint solve and records the reason in
`partition.notes`.

Transient coherent inputs and output-field observables are defined at the
complete network reference plane. Automatic simulation therefore keeps those
requests on the ordinary joint solve; internal observables may still use
component solves. An active cascade's endpoint devices remain in one group,
and its restricted field subgraph travels with that group's sub-chip; an
independent line on another device can still split off. The resolved support
remains available as `chip.resolve().dynamical_supports` for inspection.
